# Contributing to Snap7 Fork

Thanks for your interest in improving this project!

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Follow the code style** – C++ code should follow the existing patterns; Python code should be formatted with `ruff`.
3. **Test your changes** – run `python scada_dashboard.py --simulate` to verify the UI works.
4. **Write clear commit messages** (e.g., `fix:`, `feat:`, `docs:`).
5. **Submit a Pull Request** describing what you changed and why.

## Reporting Issues

Please use the GitHub issue tracker and include:
- A clear description of the problem.
- Steps to reproduce.
- Your environment (OS, compiler version, Python version).

Thank you for helping build better industrial software!
